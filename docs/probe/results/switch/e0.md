- the engine writes the tape (`markets tape RUN --inst ID --ticks 2000`) and runs it (`markets run

  switch pop's `pool.share`), with the tape's coefficients (a cost shock at genesis included),
  both efficiencies and its `rate.switch.*`;

  share (absolute); each switch pop's pool share after the tick (absolute, and in log where both

  CSV's `swgap_<pop>` against the mirror's `gap_r`);
- the mirror is run again from each genesis coin moved one ulp.

**The runs** (SPEC §7 E0): IS1 `hold`, `p[labour]*2`, `RW(2)`, `RW(0.5)`, `JB(0.5)`, `x*/2`,
